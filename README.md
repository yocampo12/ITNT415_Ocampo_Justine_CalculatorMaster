# Calculator Master

## Student Name
Justine Ocampo

## Course and Section
ITNT415 - BIT42

## Project Description
A menu-driven Python calculator developed using Git and GitHub branching.
Instead of a plain numbered menu, the interface uses custom codenames
(NEVER GROW OLD, KURAKOT, MAMAAA, KKB, EXIT) mapped to addition, subtraction,
multiplication, division, and exit. Each operation was developed on its own
feature branch and merged into main via Pull Requests.

## Branch Structure
- addition_Ocampo
- subtraction_Ocampo
- multiplication_Ocampo
- division_Ocampo

## Program Features
- Custom-themed menu-driven interface
- User input validation (numeric + menu choice)
- Continuous execution until "EXIT" is selected
- Proper function definitions for each operation
- Error handling for invalid entries
- Division-by-zero handling
